FLA7PRO: soil moisture profiling for smart irrigation

Real-time monitoring and autonomous smart irrigation, documented on youtube.com/@FLA7PRO

Irrigation shouldn't depend on one surface reading. This project builds a vertical soil profile so decisions reflect the root zone.

  • Custom multi-depth probe with helical capacitive electrodes and temperature sensing at several levels
  • Signal conditioning (TLV272 stage) and temperature-assisted interpretation
  • Two months of experiments on black, red and brown soils, interpreted with KNN and MLP
  • Local network: nodes cross-check neighbours to flag failed sensors, no cloud needed

Status: laboratory proof-of-concept (TRL-4 style). Roadmap items are planned, not deployed.

  1. Probe
  2. Conditioning
  3. Validation
  4. KNN / MLP
  5. Decision
  6. Dashboard + SQLite log
